# 🤖 Telegram Gemini AI Bot

A free, powerful AI chatbot for Telegram using Google's Gemini AI. Answers general knowledge questions, analyzes images, and helps with coding!

## ✨ Features

- 💬 **Smart Conversations** - General knowledge & Q&A
- 🖼️ **Image Analysis** - Describe and analyze images
- 💻 **Code Help** - Programming assistance
- 🧮 **Math Solver** - Solve calculations
- 🌍 **Multi-language** - Hindi, English, etc.
- ⚡ **Fast Response** - Powered by Gemini Pro

## 🚀 Quick Setup

### 1. Get API Keys
- **Telegram Bot**: Message [@BotFather](https://t.me/botfather)
- **Gemini AI**: Get free key from [Google AI Studio](https://makersuite.google.com/app/apikey)

### 2. Install & Run
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/telegram-gemini-bot.git
cd telegram-gemini-bot

# Install dependencies
pip install -r requirements.txt

# Setup environment variables
cp .env.example .env
# Edit .env with your API keys

# Run bot
python bot.py
